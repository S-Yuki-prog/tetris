# Tetris (Local Practice Project)

A single-file, offline-playable Tetris built as a hands-on trial run of working with Claude.

## How to play

Just download `tetris.html` and open it in any modern browser — no server, no build step, no internet connection required.

## Controls

| Key | Action |
|---|---|
| ← / → | Move |
| ↓ | Soft drop |
| ↑ | Rotate |
| Space | Hard drop |
| C | Hold piece |
| P | Pause |

## Features

- 7-bag randomizer for piece order
- Ghost piece (landing preview)
- Hold + Next piece panels
- Standard scoring with level-based speed increase
